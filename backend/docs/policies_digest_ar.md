# موجز سياسات وامتثال (قطر)

- **حماية البيانات الشخصية – قطر (PDPPL 13/2016)**: ينطبق على كل معالجة إلكترونية للبيانات الشخصية، مع تشديد إضافي على بيانات الأطفال والصحة. يجب تشفير هذه الحقول وتقييد الوصول لها وتسجيل كل عملية وصول/تغيير. راجع النص الرسمي عبر البوابة القانونية القطرية. 
- **الاعتماد الوطني QNSA**: المدرسة تحتاج أدلة جودة وخطط تحسين ومؤشرات أداء – جداول `quality_evidence`, `improvement_plan`, `kpi_snapshot` تدعم ذلك.
- **هيكل MoEHE (قرار أميري 35/2022)**: يحدد إدارات مثل شؤون المدارس والطلبة، المناهج، تقييم الطلبة، مركز التدريب؛ صيغ RBAC/ABAC لدى الباك‑إند تعكس هذا التقسيم.
- **الدفاع المدني**: جداول الأصول/الغرف وشهادات السلامة توثّق الالتزام بدليل المتطلبات الفنية، مع إرفاق روابط الشهادات وتواريخ الصلاحية.
